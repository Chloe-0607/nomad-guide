# NOMAD / BRIEFING｜數位遊牧上手指南

以登機說明書為概念的 Vibe Coding 課程作品。從遠端職能、自媒體內容，到城市規劃示例與行前清單，整理新手需要的入門資訊。

## 操作方式

直接以瀏覽器開啟 `index.html`，不需安裝。網站全部樣式、JavaScript 與 SVG 都在單一檔案裡。

- 點選曼谷、清邁、東京或峇里島，切換城市資訊。
- 點選三張職能手冊，展開學習路徑。
- 勾選十二項行前清單，進度自動保留在目前瀏覽器。
- 點「重設行前清單」，確認後重新準備。

清單不跨裝置同步，也不會上傳；清除瀏覽器網站資料會移除紀錄。本機檔案與公開網站的儲存互不共用。

## 檔案

- `index.html`：完整可操作網站，也是作業指定的單檔成品。
- `規格書.md`：構想、受眾、功能、視覺、資料限制及驗收標準。
- `驗證紀錄.md`：實際檢查結果及發布狀態。

## GitHub Pages

儲存庫使用 `main` 分支根目錄提供網站。設定位置：Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save。

發布完成與否請見驗證紀錄；不能只以檔案已上傳作為網站已上線的證據。

設定方式參照 [GitHub 官方文件](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 資料說明

城市生活費及網路資訊為原稿示例，尚未逐項查證，沒有即時行情 API。簽證摘要附官方來源；個人申請資格與最新規定需自行核對。網站沒有 Email 訂閱、付款或後端系統。
