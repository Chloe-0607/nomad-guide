MODULE 01 · 起飛前的觀念

為什麼「工作地點」
不再是問題

CLASS 01

傳統辦公室職涯

  • —常有固定工時，部分職務也採成果評估
  • —工作地點被辦公室座位固定
  • —經驗與人脈可累積，工作安排依公司制度而異
  • —成長曲線跟著升遷制度走

CLASS 02

遠端 / 接案工作

  • ＋收入與「交付成果」綁定，產出即報酬
  • ＋需協調網路、時區、雇主規範與合法工作資格
  • ＋資產是可攜帶的技能與作品集
  • ＋成長曲線由自己接的案子與客戶決定

SKILL 01 · 搜尋與內容

SEO 搜尋引擎優化

讓網站被 Google 看懂、被使用者找到，是不受地點限制、能長期累積的自然流量技能。

展開先備知識與學習路徑 ▾

先備知識

不需要會寫程式，但要看得懂基本 HTML 標籤（標題、段落、連結）與網站結構概念，方便跟工程師溝通技術性調整。真正的門檻其實是「同理使用者搜尋意圖」的邏輯思考，比技術能力更重要。

4 階段學習路徑

  1. 核心觀念：搞懂爬取（Crawling）、索引（Indexing）、排名（Ranking）三步驟
  2. 關鍵字研究：用工具找出主題受眾實際在搜尋的字詞，規劃主題集群
  3. 站內實作：網站架構、標題與內文優化、內部連結、頁面速度
  4. 站外與數據優化：反向連結、Search Console 數據回饋、持續調整

常用工具

Google Search Console Ahrefs PageSpeed Insights

免費資源

Google 官方 Search Central 入門指南、Google 搜尋中心部落格、Ahrefs 官方部落格與 YouTube 頻道，都是不用花錢就能扎穩基礎的第一手資料。

新手起步任務：挑一個你懂的主題開一個部落格，針對 10 個長尾關鍵字各寫一篇文章，實際跑一次「研究 → 寫作 → 用 GSC 看數據 → 修改」的循環。

SKILL 02 · 資料與洞察

數據分析

把分散在各平台的數字，整理成一眼看懂的儀表板，是遠端證明成果最直接的方式。

展開先備知識與學習路徑 ▾

先備知識

基礎試算表操作（篩選、樞紐分析）與看得懂常見指標（曝光、點擊率、轉換率）即可入門；懂一點統計概念（平均、趨勢）對判讀數據更有幫助，但不是必要條件。

學習路徑

  1. 先學 GA4：安裝、看懂使用者與流量來源報表
  2. 串接 Looker Studio：把 GA4、Search Console 資料來源連進報表
  3. 動手做：拖拉圖表、設定篩選器與日期區間，做出第一份可分享的報表
  4. 進階：多資料來源整合（Google Ads、社群數據）、自訂公式與排程寄送

常用工具

GA4 Looker Studio Meta Business Suite

免費資源 / 認證

Google 提供官方的 Google Analytics 認證與 Looker Studio 教學影片，皆免費線上取得，是把履歷「量化」的最快方式。

新手起步任務：替自己的部落格或任一個人網站，串接 GA4 + GSC，做出第一份 Looker Studio 報表。

SKILL 03 · 策略與成效

Paid Media 廣告投放

替品牌管理廣告預算與成效，技能可遷移性高，遠端也能操盤。

展開先備知識與學習路徑 ▾

先備知識

基本的預算與比例計算（例如 CPC、CPA、ROAS 怎麼算出來）、對受眾輪廓的敏感度，以及願意持續做 A/B 測試、看數據找規律的耐性。

學習路徑

  1. 認識平台機制：Meta Ads Manager、Google Ads 後台介面與投放邏輯
  2. 策略規劃：設定受眾、預算與素材切角
  3. 執行與觀察「學習期」：觀察期間依平台、預算與轉換量而異，記錄調整與成效
  4. 成效優化：透過 CPC、CPA、CTR、ROAS 等指標做 A/B 測試迭代

常用工具

Meta Ads Manager Google Ads Meta Business Suite

免費資源 / 認證

Google Skillshop 提供免費的 Google Ads 各類認證（含廣告素材認證），Meta 也有官方免費課程，是新手建立可信度最直接的方式。

新手起步任務：先用模擬預算規劃受眾、素材與成效指標；決定實際投放時，再設定可承擔的總額與停止條件。

ACTION · 接案篇

Upwork 新手實戰 5 步驟

  1. 註冊帳號，如實填寫擅長的技能與作品，先閱讀平台規範
  2. 先看同領域前輩的簡介怎麼寫，抓格式再改寫成屬於自己的版本
  3. 用篩選器找「已驗證付款」且「提案人數少於 5 人」的案子，被看見的機率更高
  4. 確認需求、期限、交付項目與付款方式，再評估是否適合承接
  5. 挑選符合能力與時間的案子，寫客製提案並記錄回覆情況

ACTION · 被動收入篇

打造第一個數位商品 5 步驟

  1. 想一個「非常小」但真的解決某個問題的點子，不用一開始就求完整
  2. 比較 Gumroad 或 Portaly 等平台的費用與收款條件，選擇合適方案
  3. 先用很低的價格（哪怕只要 1 美元）上架，用「有沒有人願意付錢」驗證這個點子
  4. 把驗證過的商品結合自媒體內容導流，讓短影音或文章成為商品的入口
  5. 依照實際銷售數據與買家回饋，逐步擴充功能或做出進階版本再加價銷售

MODULE 02 · 打造個人 IP

短影音，
是你的免費機票

流量密碼不是運氣，是可以拆解的結構。從 Hook 到導流，一支 Reels / Shorts 依序完成四個任務。

01

0–5 秒

爆款鉤子 Hook

開場先丟出衝突句，不要用「大家好我是⋯」暖場，前幾秒沒留住人，後面講再好都白費。

02

5–20 秒

痛點放大

具體描述觀眾正在經歷的處境，讓他覺得「這支影片在講我的事」，建立情緒共鳴。

03

20–45 秒

解方＋視覺設計

只講一個重點，字幕加大加粗（多數人靜音滑手機），節奏明快、刪掉多餘的連接詞。

04

45–60 秒

CTA 導流

問一個能讓人留言的問題，或導向作品集、信箱名單，把流量變成可累積的資產。

HOOK LIBRARY

8 種常見鉤子類型，直接套用

01 · 痛點法

直接點出觀眾正在困擾的問題，讓他意識到「我好像有這個困擾」。

02 · 錯過遺憾法

製造「現在不看會後悔」的急迫感，利用錯失恐懼留住注意力。

03 · 好奇法

丟出一個懸而未解的問題或不尋常情境，讓人想繼續看下去。

04 · 快速教學法

直接承諾「很快能學會一件事」，讓觀眾覺得值得花時間看完。

05 · 前後對比法

用 Before / After 的反差，激起對「轉變過程」的好奇心。

06 · 經驗數據法

開頭就亮出具體成果或數字，用實績快速建立說服力。

07 · 爭議觀點法

挑戰觀眾既有的認知，故意唱一點反調，激起討論與好奇。

08 · 警告提醒法

用「這件事不要做」開場，製造「踩雷預防」的安全感與急迫性。

建議用 A/B 測試找出你的受眾偏好哪一種鉤子，再持續複製成功模式。
